# 要件定義（たたき台）

最終更新: 2026-10-27（火）

## 1. 目的

符計算・点数計算ができなくても、和了のたびにスマホで正しい点数がわかるようにする。
あわせて、半荘（東風戦）を通した持ち点を管理し、点棒のやり取りの間違いをなくす。

## 2. 使う場面

- 自分が卓にいるとき、自分のスマホ1台で操作する（想定。→ 未決 Q4）
- 1局終わるたびに、和了した手を入力して点数を出す
- 対局の最初に、席と東風戦・東南戦を設定する

## 3. 機能（案）

### 3.1 対局の設定（1戦の始まりに1回）

- 4人の名前と、起家（最初の東家）からの席順（東・南・西・北）
- 東風戦 / 東南戦
- 持ち点（例: 25,000点持ち・30,000点返し）
- ルール（赤ドラの有無、喰いタン、後付け、場ゾロなど → 未決 Q3）

### 3.2 1局ごとの入力

| 入力すること | 理由 |
|---|---|
| 和了した人 | 親か子かを判定する（席と局から自動で決まる） |
| ツモ / ロン（ロンなら放銃した人） | 誰が払うかを決める |
| 手牌14枚と和了牌 | 役・符を判定する。待ちの形は和了牌から自動で判定し、高い方を採る |
| 鳴いた面子（ポン・チー・明槓）・暗槓 | 門前かどうか、符が変わる |
| ドラ表示牌（裏ドラ・槓ドラも） | ドラの数を数える |
| 立直・一発・海底/河底・嶺上開花・槍槓・天和/地和など | 手牌だけではわからない役 |

自動で決まるもの: 場風（局から）、自風（席から）、本場、供託の立直棒の数。

入力の方法は2つを考えている。

1. 牌を画面でタップして入力する
2. 手牌の写真を撮り、AI が牌を読み取る → 読み取り結果を画面で確認・修正してから計算する

### 3.3 計算と表示

- 役の一覧、翻数、符（内訳つき）、点数
- 誰が誰に何点払うか（本場を含む。供託は含めない）
  - 供託の立直棒は自動雀卓が和了した人に渡すため、表示しない
- 計算のあと、全員の持ち点を更新する
  - 持ち点には、立直した人の −1,000点と、和了した人が受け取る供託の分も入れる（卓の表示と合わせるため）

### 3.4 局の進行と点棒管理

- 親の連荘・流局（テンパイ料）・本場の積み上げ
- 途中流局（九種九牌など）
- 半荘の終わりの判定（飛び、オーラスなど）と最終順位・ウマ/オカの計算
- 終局のとき、アプリの持ち点を卓の表示と見比べて直せるようにする（入力ミスがあっても成績を正しく残すため）
- 1局前に戻す（入力ミスのやり直し）

## 4. 方針

- **点数の計算は AI に任せず、プログラムで決まった通りに計算する。** AI は符計算をよく間違えるため。AI を使うのは写真から牌を読み取るところだけにする
- スマホのブラウザで開ける Web アプリにする。ホーム画面に追加すればアプリのように使える（PWA）
- 写真を使わない部分はネットがなくても動くようにする

## 5. 写真の読み取りについて（検討事項）

- 画像から牌を読み取るには AI の API（Claude など）を呼ぶ必要がある
  - API の鍵をブラウザに置けないため、小さなサーバー（例: Cloudflare Workers）が要る
  - 1回の読み取りごとに少額の利用料がかかる（目安は後で調べる）
- 読み取りは間違えることがあるので、必ず確認画面をはさむ

## 6. 決まったこと（2026-10-27）

| 項目 | 決定 |
|---|---|
| 最初の版の範囲 | 点数計算＋点棒管理（3.1〜3.4 すべて） |
| 写真の読み取り | 後の版で足す。最初の版はタップ入力だけ |
| ルール | 一般的なアリアリ。よく変わる所だけ設定できるようにする（7章） |
| 使う人 | 自分のスマホ1台。サーバーは使わず、データはスマホの中に保存する |
| 三人麻雀 | 対応しない（四人麻雀だけ） |
| 成績の記録 | 残す（9章） |
| 支払いの表示 | 和了の点数＋本場の分。供託は自動雀卓が渡すので表示しない（持ち点の計算には入れる） |
| 立直の入力 | 局の終わりの入力でまとめて選ぶ |

## 7. ルール（初期値の案・要確認）

「設定」の列が ○ のものは、対局の設定で変えられるようにする。

| 項目 | 初期値 | 設定 |
|---|---|---|
| 持ち点 / 返し | 25,000点持ち / 25,000点返し（オカなし） | ○ |
| ウマ | 10-20 | ○ |
| 赤ドラ | 各色の5に1枚ずつ（計3枚） | ○ |
| 喰いタン | あり | ○ |
| 後付け | あり（アプリでは判定しない。和了の形だけでは決められないため） | |
| 切り上げ満貫（30符4翻・60符3翻） | なし | ○ |
| ダブル役満 | あり（国士無双十三面・四暗刻単騎・純正九蓮宝燈・大四喜）。役満の複合もあり | ○ |
| 数え役満（13翻以上） | あり | |
| 連風牌の雀頭 | 2符 | |
| 本場 | 1本場300点 | |
| 供託の立直棒 | 次に和了した人が取る。終局時に残ればトップが取る | |
| 飛び | あり（0点未満で終了） | ○ |
| 西入（返し点に届かないとき延長） | なし | |
| 流し満貫 | あり | |
| 途中流局（九種九牌・四風連打・四家立直・四開槓） | あり（三家和はトリプルロンで和了にするため、なし） | |
| ダブロン | あり。本場と供託は、放銃した人から見て順番が近い人（上家取り）が両方とも取る | ○ |
| トリプルロン | あり（3人とも和了）。本場と供託はダブロンと同じく上家取り | |
| 親の連荘 | 和了またはテンパイで連荘（ダブロン・トリプルロンでは、和了した人に親が入っていれば連荘） | |
| オーラスの和了止め・テンパイ止め | あり（親がトップなら終了できる） | |
| 責任払い（パオ） | 大三元・大四喜 | |

## 8. まだ決めていないこと

- なし（技術と作る順番は README に書いた）

作った中で、簡単にしてあるところ:
- 責任払い（パオ）は大三元・大四喜のときに選べる。ツモは責任者が全額、ロンは放銃者と責任者で半分ずつ（本場は責任者）。役満が重なっていても、全額を責任払いの対象にしている
- 流し満貫は満貫のツモと同じ払い方で、本場は付けない。流し満貫があればテンパイ料はなし
- 人和は入れていない（ローカル役のため）

## 9. 成績の記録

- よく打つ人の名前を登録しておき、対局の設定で選ぶ（毎回入力しない）
- 対局ごとに残すもの: 日付、4人の名前と席、最終の点数、順位、ウマ込みのスコア、各局の結果
- 人ごとに見られるもの: 対局数、平均順位、1〜4位の回数、トップ率・ラス率、合計スコア、和了率・放銃率
- 期間（月ごとなど）で絞り込める
- データはスマホの中に保存するので、機種変更に備えてファイルに書き出し・読み込みできるようにする

## 10. 画面の流れ（案）

```
ホーム ─┬─ 新しい対局 → 対局の設定 → 局の画面 ⇄ 和了の入力 → 結果の確認
        │                              ⇄ 流局の入力
        │                              → 終局（順位・スコア → 成績に保存）
        ├─ 続きから（途中の対局に戻る）
        ├─ 成績（人ごとの一覧 → 個人の詳細／対局の履歴）
        └─ 設定（メンバーの登録、ルールの初期値、データの書き出し・読み込み）
```

| 画面 | 内容 |
|---|---|
| 対局の設定 | メンバーから4人を選ぶ → 席（東南西北）を決める → 東風／東南 → ルール（初期値から変える所だけ） |
| 局の画面 | 「東2局 1本場 供託1」と4人の持ち点を卓の形で表示。ボタンは「和了」「流局」「1局戻す」 |
| 和了の入力 | ① 和了した人（複数選べる＝ダブロン）② ツモ／ロン（ロンなら放銃した人）③ 手牌（牌の一覧をタップ。鳴いた面子は「ポン」「チー」などを選んでから入れる）④ 和了牌 ⑤ ドラ表示牌・裏ドラ ⑥ 立直した人、一発・海底などの役 |
| 結果の確認 | 役・翻・符の内訳・点数・誰が誰にいくら払うか。「確定」で持ち点を更新 |
| 流局の入力 | テンパイした人を選ぶ／途中流局の種類／流し満貫／立直した人 |
| 終局 | 最終の点数（卓の表示と違えば直す）・順位・ウマ込みのスコア。「保存」で成績に残す |

立直は、局の途中では操作せず、局の終わりの入力でまとめて選ぶ（卓でスマホを触る回数を減らすため）。
